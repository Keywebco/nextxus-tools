# NextXus Tools

The Federation tools directory: every working NextXus tool collected in one place, organized by category. It is for anyone in the Federation who wants to find the right tool without hunting across sites.

**Live:** https://keywebco.github.io/nextxus-tools/

## What's listed

- **Thinking and decision tools** — Ring of 12, Ring of 12 on the Throne, Truth Gate Core, Roger Sim AI
- **Workspace and knowledge tools** — Federation Browser Base, Sovereign Knowledge OS, Federation Mind Mirror, God's-Eye View, Plexus Relay
- **Security** — OneKey
- **Rooms and boards** — Meeting Room (Outer), Meeting Room (Inner), Emmy Board, Nova Board, Messages Feed
- **Build templates** — Agent Zero, Satellite Starter, Markdown Outpost, Directives Outpost, Federation Directory

## Notes

- Single static page (`index.html`) — a directory of links with status tags, not the tools themselves.
- Each card links out to the tool's own site or page.
